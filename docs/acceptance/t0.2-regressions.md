# T0.2 regression coverage

These tests encode the six priority findings from the evolution plan as
regressions. They specify expected behavior; passing tests do not by themselves
certify integrations with external agent runtimes.

| Finding | Regression and expected behavior |
| --- | --- |
| Generation drops skills or gate workspaces | `TestGeneratePreservesSkillsAndStructuredQualityGates` checks approved skills and all workspace fields reach the adapter. |
| Generated-file ownership can overwrite human edits | `TestWriterProtectsManualFilesAndAllowsOwnedRegeneration` requires a conflict and byte preservation after a generated file is manually edited. |
| Approval is not bound to reviewed content/evidence | `TestApprovedRuleRequiresReReviewWhenContentOrEvidenceChanges`, `TestGenerateRejectsReviewedRuleChangedAfterApproval`, and `TestGenerateRejectsEvidenceChangedAfterApproval` require re-review before publication. |
| Discovery treats a reused ID as automatically idempotent | `TestStoreAcceptsSameIDWithIdenticalContent` allows identical replay; `TestStoreRejectsSameIDWithDifferentContent` rejects divergent content without changing the source. |
| Drift equates symbol presence with conformance | `TestDetectShowsAlignedDifferenceAndUnsupportedRule` separates evidence presence from `not_evaluated` conformance and reports absent evidence independently. |
| Layout resolution silently chooses between `.harness` and `.forge` | `TestResolveLayoutSelectsSingleSourceAndRequiresChoiceForCoexistence` requires explicit selection when both layouts exist; `TestResolveReferenceRejectsTraversalAndPreservesProjectRelativePaths` covers safe relative references. |

Run the focused regression set with:

```text
go test ./internal/generation/... ./internal/harness/... ./internal/discovery/... ./internal/drift/...
```
