Date: 2026-09-27. This is deterministic repository-level acceptance; it does
not claim measured improvement in agent task quality.

and the CLI:


## Static clone fixture

`testdata/clones/without-forge/` contains separate Codex and Claude Code clones.
Each has its native instruction file and a small Go project; neither includes a
`.harness/`, `.forge/`, generation manifest, or HarnessForge binary. The focused
`TestWithoutForgeClonesPreserveExportedContract` test checks those absences,
required approved rule text, skill references and contents, the test gate, and
the independent Go module manifest for both clones.

No task agent/model request was run against the fixture. A local Codex CLI
prompt-input check is recorded below; it verifies discovery for that exact build,
not whether a model follows every instruction. Claude runtime discovery and the
versioned adapter acceptance remain separate.
