## Static clone fixture

`testdata/clones/without-forge/` contains separate Codex and Claude Code clones.
Each has its native instruction file and a small Go project; neither includes a
`.harness/`, `.forge/`, generation manifest, or HarnessForge binary. The focused
`TestWithoutForgeClonesPreserveExportedContract` test compiles and syncs a
temporary copy of the canonical Forge source, then compares every generated
instruction and skill byte-for-byte with the two consumer clones. It rejects
extra or stale native outputs and checks that the clones contain no Forge
configuration or generated ownership manifest. Each clone has an independent
Go module manifest.

On 2026-09-30, that focused test passed, and `go test ./...` completed in each
clone. The clone modules have no dedicated Go test files, so these commands
verify buildability and module resolution rather than task behavior.

No task agent/model request was run against the fixture. A local Codex CLI
prompt-input check is recorded below; it verifies discovery for that exact build,
not whether a model follows every instruction. Claude runtime discovery and the
versioned adapter acceptance remain separate.
